# 每日選聞

每日台股新聞自動篩選工具。只收錄**同時**滿足兩個條件的新聞:

1. **內文重點**:內容涉及以下七類之一
   漲價缺貨/新產品‧新應用/國家政策/產業超成長/高資本支出/技術領先/國際熱賣
2. **公司高層**:內文有公司高層(執行長、董事長、總經理、副總經理、財務長)發言或公司聲明,或標題帶「澄清」

👉 **線上使用:https://twstockradar.github.io/news-filter/**

## 使用方式

- **8 顆分類籤**:點選切換,可多選(顯示命中任一所選分類的新聞);「公司高層」籤只顯示高層具名發言的新聞
- **搜尋框**:輸入族群或關鍵字(如「伺服器」「散熱」),即時過濾;空格分隔多詞 = 同時滿足
- **週曆**:‹ › 切換週次,點日期只看當天,再點一次取消
- 每則新聞:標題(連到原文)、命中的關鍵字、摘要與縮圖;同事件的多則報導自動收合為「另有 N 則相似報導」

## 自行架設

```
pip install -r requirements.txt
python fetch_news.py        # 初次回補 30 天(INITIAL_DAYS 可調)
# 打開 docs/index.html 即可使用
```

之後定期跑 `run_update.bat`(增量更新 + 自動 push)。
調整篩選關鍵字:編輯 `keywords.json` 後跑 `python fetch_news.py --rescan`。

## 聲明

新聞著作權屬原媒體(鉅亨網)所有,本工具僅整理標題、摘要與原文連結。內容僅供參考,非投資建議。
